# Logos

The JLab mark: a rounded square with a lowercase j and a live status dot. Use `jlab-mark-dark.svg` on dark grounds (`bg`, `panel` in Dark) and `jlab-mark-light.svg` on light grounds. In the product the dot follows lab health: `running` when healthy, `degraded` with an issue, a hollow ring when offline. Minimum size 16 px. Pair with the word "JLab" in Mona Sans 600; never stretch, outline or recolour the square.
