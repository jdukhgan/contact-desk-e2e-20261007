# Breadcrumb

Breadcrumbs follow the resource hierarchy and collapse the middle when long. Pagination shows the range and total; tables over 500 rows paginate, shorter ones scroll.

## Breadcrumb

- **Build with:** shadcn `breadcrumb`
- **Rules:** Follows resource hierarchy; collapses middle to "…"

## Pagination

- **Build with:** shadcn `pagination`
- **Rules:** Range and total on the left ("51 to 100 of 1,240"); paginate only above 500 rows

## Tokens used

`line-heavy`, `text-3`, `text`
