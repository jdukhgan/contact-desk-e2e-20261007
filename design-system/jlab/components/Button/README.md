# Button

Four variants, two sizes. Press scales to 0.97 in 160 ms. Labels name the exact action.

## Button

- **Build with:** shadcn `button` (replaced by our file)
- **Variants:** default (inverted primary), secondary, ghost, destructive, link; sizes sm 26, default 30, icon, icon-sm
- **Rules:** Press scales 0.97 in 150 ms. Working state keeps width and swaps the verb ("Starting"). Labels name the action.
- **Keyboard:** Enter, Space

## Tokens used

`hover`, `line-strong`, `raised`, `text-2`, `text-3`, `text`
