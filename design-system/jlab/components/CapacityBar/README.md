# CapacityBar

4 px bars with the value and the real limit above. Fill turns amber past 80%, red past 95%. Stale bars turn dashed.

## Capacity bar

- **Build with:** jlab `CapacityBar`
- **Variants:** normal, ≥80%, ≥95%, stale
- **Rules:** 4 px; value and limit above; dashed when stale

## Allocation bar

- **Build with:** composed
- **Rules:** Stacked 10 px bar, scale = real capacity, series in fixed order, legend with values

## Tokens used

`degraded`, `down-text`, `down`, `line-strong`, `series-1`, `series-2`, `series-3`, `series-4`, `series-5`, `text-2`, `text-3`
