# Choice

Checkbox, toggle and segmented control. Toggles act immediately; checkboxes wait for a save.

## Checkbox

- **Build with:** shadcn `checkbox`
- **Variants:** off, on, indeterminate
- **Rules:** Checked fill is `bg-primary`
- **Keyboard:** Space

## Switch

- **Build with:** shadcn `switch`
- **Rules:** 28 × 16; acts immediately, never inside a form that needs Save
- **Keyboard:** Space

## Segmented control

- **Build with:** shadcn `toggle-group`
- **Rules:** Inset group on `bg-background`, selected item raised with ring
- **Keyboard:** Arrows

## Tokens used

`bg`, `line-heavy`, `line-strong`, `line`, `primary-text`, `primary`, `raised`, `text-2`, `text`
