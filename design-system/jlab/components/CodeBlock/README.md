# CodeBlock

Code blocks with a copy button and language label. The terminal is an embedded console with its own dark surface in both themes. Diffs show file, line numbers and change counts.

## Code block

- **Build with:** composed
- **Rules:** Language label and Copy button in a header row

## Terminal

- **Build with:** xterm.js
- **Rules:** Own near-black surface in both themes, connection status in header
- **Keyboard:** Full keyboard

## Diff viewer

- **Build with:** composed
- **Variants:** unified, split
- **Rules:** File path, +/− counts, two line-number columns

## Tokens used

`down-bg`, `down-text`, `line`, `running-bg`, `running`, `text-2`, `text-3`
