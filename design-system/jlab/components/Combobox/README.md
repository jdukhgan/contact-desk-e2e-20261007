# Combobox

Search inside the list, match text highlighted, status inline. Multi-select shows chosen values as removable tags in the field.

## Combobox

- **Build with:** shadcn `popover` + `command`
- **Variants:** single, multi (tags)
- **Rules:** Match highlighted in bold; "Create …" row last; multi shows removable tags, collapses past 3
- **Keyboard:** Arrows, Enter, Backspace removes last tag

## Tokens used

`hover`, `line`, `text-2`, `text-3`, `text`
