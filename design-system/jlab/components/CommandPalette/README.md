# CommandPalette

⌘K opens instantly with no animation. Results group by kind with status inline. Actions that change things say they need approval.

## Command palette

- **Build with:** shadcn `command` in dialog
- **Rules:** Opens with no animation; groups by kind; status inline; actions that change things say "Needs approval"; empty state offers "Ask agent instead"
- **Keyboard:** ⌘K, arrows, Enter, ⌘Enter asks agent

## Tokens used

`hover`, `line`, `pop`, `raised`, `text-2`, `text-3`
