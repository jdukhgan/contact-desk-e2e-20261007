# DataStates

Loading, empty, error and stale, shown here for a table. Charts and lists follow the same rules.

## Empty state

- **Build with:** composed
- **Variants:** none yet, filtered empty
- **Rules:** Names what is missing and offers one next step; filtered empty offers Clear filter

## Skeleton

- **Build with:** shadcn `skeleton`
- **Rules:** `bg-raised`, final layout and height, no shimmer

## Tokens used

`down`, `line-strong`, `raised`, `text-2`, `text-3`
