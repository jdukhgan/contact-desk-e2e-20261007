# DateRange

Presets first, calendar second, because most ranges in a lab are "last 24 hours". Times use 24-hour format with the time zone shown.

## Date range

- **Build with:** shadcn `calendar` + `popover`
- **Rules:** Presets column first; 24-hour times with time zone
- **Keyboard:** Arrows in grid

## Tokens used

`hover`, `line-heavy`, `line`, `pop`, `primary-text`, `primary`, `raised`, `text-2`, `text-3`
