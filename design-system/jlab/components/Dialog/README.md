# Dialog

Only for decisions that need protected focus, such as destroying data. Centered, no scale origin. The confirm button stays disabled until the name is typed.

## Dialog

- **Build with:** shadcn `alert-dialog`
- **Variants:** destructive confirm
- **Rules:** Only for destroying data. Title asks the question with the name; body says what is lost and kept; type-the-name to enable the destructive button; Enter never confirms
- **Keyboard:** Escape, Tab trapped

## Tokens used

`down`, `focus`, `line`, `panel`, `pop`, `raised`, `text-2`, `text`
