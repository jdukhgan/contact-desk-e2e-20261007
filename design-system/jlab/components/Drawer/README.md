# Drawer

Drawers slide from the right over the content for quick edits without leaving the page. Popovers hold one short form. Context menus mirror the row's action menu.

## Drawer

- **Build with:** shadcn `sheet`, side right
- **Rules:** 320 px; header with close, body, footer with primary first
- **Keyboard:** Escape

## Popover form

- **Build with:** shadcn `popover`
- **Rules:** One short form, Cancel and primary bottom right
- **Keyboard:** Escape

## Tokens used

`down-text`, `line`, `panel`, `text-3`
