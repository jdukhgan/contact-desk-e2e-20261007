# FileUpload

A drop zone that also works as a button. Each file shows progress, then success or a specific error.

## File upload

- **Build with:** composed
- **Rules:** Dashed drop zone that is also a button; per-file progress, success, specific error with Retry
- **Keyboard:** Enter opens picker

## Tokens used

`down-text`, `down`, `info`, `line-heavy`, `primary-text`, `running`, `text-2`, `text-3`
