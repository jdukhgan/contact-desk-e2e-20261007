# Input

32 px fields on the panel colour. Labels above, help and errors below. Errors say what is wrong and how to fix it.

## Input

- **Build with:** shadcn `input`
- **Variants:** default
- **Rules:** `h-8 rounded-md bg-card border-input`; focus ring blue with 3 px soft halo; error border `destructive/60` plus message below saying how to fix
- **Keyboard:** Standard

## Input with unit

- **Build with:** composed
- **Rules:** Unit in a joined right segment, `text-subtle-foreground`

## Select

- **Build with:** shadcn `select`
- **Rules:** Options show status or capacity on the right; unavailable options stay visible with the reason
- **Keyboard:** Arrows, type-ahead

## Tokens used

`degraded`, `down-bg`, `down-text`, `focus`, `hover`, `line-heavy`, `line-strong`, `text-3`, `text`
