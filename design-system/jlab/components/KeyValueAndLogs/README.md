# KeyValueAndLogs

Key and value lists for resource facts. Logs in mono with a level column; warnings and errors tint only their level.

## Key-value list

- **Build with:** composed
- **Rules:** `dl`, 96 to 110 px label column in `subtle-foreground`, mono values where technical

## Log viewer

- **Build with:** composed
- **Rules:** Mono rows: time, level, message; only WARN and ERROR rows tint

## Tokens used

`degraded-bg`, `degraded`, `down-bg`, `down-text`, `line`, `running`, `text-3`
