# LineChart

Unit in the title, labelled axes with the maximum, a labelled threshold, and a crosshair that reads exact values. Drag across the plot to zoom, as in Railway's 2026 observability panels.

## Line, bar, stacked area chart

- **Build with:** shadcn `chart` (Recharts)
- **Rules:** `chart-1..5`; axis ticks 11 px mono `subtle-foreground`; gridlines `border`; thresholds dashed `warning` with legend label; crosshair tooltip on `popover`; drag to zoom
- **Keyboard:** Arrows move crosshair

## Tokens used

`degraded`, `info`, `line-heavy`, `line`, `panel`, `pop`, `raised`, `series-1`, `text-2`, `text-3`, `text`
