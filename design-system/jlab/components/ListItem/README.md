# ListItem

List rows for collections of mixed things. Cards only when items have a visual or need a grid, such as projects or templates. Never nest cards.

## List item

- **Build with:** composed
- **Rules:** 32 px icon tile, title, one meta line, status or one action on the right

## Card

- **Build with:** shadcn `card`, restricted
- **Rules:** Only for items with a visual or a grid (templates, projects). Never nested. Never as page structure

## Tokens used

`line-strong`, `line`, `raised`, `running`, `text-2`, `text-3`
