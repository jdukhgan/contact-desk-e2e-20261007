# PageHeader

One pattern on every screen: title or path on the left; freshness, time range, primary action and agent toggle on the right.

## Page header

- **Build with:** jlab `PageHeader`
- **Variants:** live, stale
- **Rules:** Stale removes the time range and hollows the live dot

## App shell

- **Build with:** jlab `AppShell`
- **Rules:** Inset rounded content panel; agent panel behaviour per breakpoint

## Tokens used

`bg`, `degraded`, `hover`, `line-strong`, `line`, `running`, `text-2`, `text-3`, `text`
