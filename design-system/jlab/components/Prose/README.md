# Prose

For docs, runbooks and agent reports. 15/24 body, 68 character measure, more space above headings than below. Links underline with a 3 px offset.

## Long-form text

- **Build with:** `prose` styles
- **Rules:** 15/24, 68 characters, links underlined with 3 px offset, inline code on `bg-hover`

## Tokens used

`hover`, `line-heavy`, `text-2`, `text`
