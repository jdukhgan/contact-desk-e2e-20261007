# SecondaryNav

Settings-style pages get a second sidebar inside the content panel. On phones the sidebar becomes a floating bottom bar for one-handed use, as Vercel shipped in 2026.

## Bottom bar (phone)

- **Build with:** composed
- **Rules:** Floating, 58 px, radius 18, `shadow-pop`, 4 items max

## Tokens used

`hover`, `line`, `panel`, `pop`, `raised`, `text-2`, `text-3`, `text`
