# Sidebar

Sits on the app background, dimmer than content. Expanded at 228 px, or a 52 px rail with tooltips. Resizable and hideable, as in Vercel's 2026 navigation.

## Sidebar

- **Build with:** shadcn `sidebar` block
- **Variants:** expanded 228, rail 52
- **Rules:** `bg-sidebar` equals the app background; items `text-muted-foreground`, hover and current `bg-hover text-foreground`; right slot is a mono count or a status dot with number

## Tokens used

`bg`, `degraded`, `hover`, `line-strong`, `line`, `panel`, `running`, `text-2`, `text-3`, `text`
