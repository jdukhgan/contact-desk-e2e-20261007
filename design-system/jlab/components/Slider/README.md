# Slider

Sliders for bounded values with the real limits labelled. Steppers for small whole numbers. Both accept typed values.

## Slider

- **Build with:** shadcn `slider`
- **Rules:** Real limits labelled; free-capacity marker in `warning`
- **Keyboard:** Arrows, Shift+Arrows

## Number stepper

- **Build with:** composed
- **Rules:** Joined − value + segments, mono value
- **Keyboard:** Arrows, Shift ×4

## Tokens used

`degraded`, `line-strong`, `primary`, `text-3`
