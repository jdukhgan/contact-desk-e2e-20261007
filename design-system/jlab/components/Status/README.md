# Status

A dot plus a word, always. Healthy text stays neutral so only problems draw the eye.

## Status

- **Build with:** jlab `Status`
- **Variants:** running, degraded, down, stopped, stale, working
- **Rules:** Dot plus word, always

## Tag

- **Build with:** shadcn `badge`, restyled
- **Variants:** identifier (mono, outline), status (tinted)
- **Rules:** `rounded-sm px-[7px] text-[11px]`; tint only when it carries status

## Tokens used

`degraded-bg`, `degraded`, `down`, `info`, `line-strong`, `running-bg`, `running`, `text-2`, `text-3`
