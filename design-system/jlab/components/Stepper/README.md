# Stepper

Steppers for set-up flows of 3 to 5 steps, with completed steps editable. Accordions group optional settings; one can be open at a time per group.

## Stepper

- **Build with:** composed
- **Rules:** 3 to 5 steps; completed steps show a check and stay editable

## Accordion

- **Build with:** shadcn `accordion`
- **Rules:** Closed sections summarise their values on the right
- **Keyboard:** Enter, Space

## Tokens used

`line-heavy`, `line-strong`, `line`, `primary-text`, `primary`, `text-3`, `text`
