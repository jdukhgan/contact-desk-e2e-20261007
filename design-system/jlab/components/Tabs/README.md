# Tabs

Underline tabs for sections of one resource. Counts in mono. The same tab set appears for every resource of the same kind.

## Tabs

- **Build with:** shadcn `tabs`
- **Variants:** underline (override the pill default)
- **Rules:** Current: 2 px foreground underline; counts in mono; same tab set for every resource of a kind
- **Keyboard:** Arrows

## Tokens used

`line`, `text-2`, `text-3`, `text`
