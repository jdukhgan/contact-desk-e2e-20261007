# TextareaAndRadio

Textarea grows with content up to 8 lines. Radio groups for 2 to 5 exclusive options; above that, use a select.

## Textarea

- **Build with:** shadcn `textarea`
- **Rules:** Grows to 8 lines, optional character count bottom right in mono

## Radio group

- **Build with:** shadcn `radio-group`
- **Rules:** 2 to 5 options, each with a one-line description
- **Keyboard:** Arrows

## Tokens used

`line-heavy`, `primary-text`, `primary`, `text-3`
