# Toast

Bottom right, stacked, 5 s by default. Errors stay until dismissed. Timers pause while the tab is hidden or the pointer is over them.

## Toast

- **Build with:** `sonner`
- **Variants:** working, success with Undo, error
- **Rules:** Bottom right, 5 s, errors persist, pause on hover and hidden tab

## Tokens used

`down`, `info`, `pop`, `primary-text`, `raised`, `running`, `text-2`
