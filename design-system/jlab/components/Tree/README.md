# Tree

For true hierarchies: host, machine, container. Indent 16 px per level, chevrons only on items with children, status at the right edge.

## Tree

- **Build with:** shadcn `collapsible`, ARIA tree
- **Rules:** 16 px indent per level, chevrons only on parents, status at right edge
- **Keyboard:** Arrows, Left/Right collapse

## Tokens used

`degraded`, `hover`, `text-3`
