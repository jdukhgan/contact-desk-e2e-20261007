# Iconography

Lucide only (`lucide-react`), at 16 px with a 1.5 px stroke, in the current text colour. 14 px inside small buttons, 18 px in the phone bottom bar. The core set is on the **Icons** card.

- Icons label structure and actions. Identity comes from names; status always comes from a dot with its word.
- Icon-only buttons need an accessible label and a tooltip with the shortcut.
- Never mix icon sets, never use emoji, never draw a bespoke icon where Lucide has one.
