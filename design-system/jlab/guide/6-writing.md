# Writing

Plain, specific and short. Sentence case everywhere.

| Write | Not |
|---|---|
| Start machine | Submit |
| Port 54322 is used by supabase. Try 54330. | Invalid port |
| mac-mini stopped reporting 14 min ago | Host unavailable |
| Restarts honcho. About 10 s without the gateway. | This may cause downtime |
| No machines on mac-mini yet. | Nothing here |

- Buttons name the exact action.
- Errors say what happened and how to fix it.
- Times in 24-hour format; durations as "4 min 12 s"; sizes with units ("27.1 / 32 GiB").
- Stale data always shows its age.
- No exclamation marks, no emoji.
